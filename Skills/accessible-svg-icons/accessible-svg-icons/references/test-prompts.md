# Test prompts

Use these prompts to test whether the skill triggers and follows its workflow.

## Create

1. Create four consistent inline SVG icons for dashboard cards showing active projects, overdue tasks, employee ideas, and completed training. Include visible labels and do not rely on colour alone.
2. Replace the emoji in this HTML page with responsive line icons that inherit the page theme.
3. Create an icon-only filter button for a dashboard and include the HTML and CSS needed for keyboard focus.
4. Create a small icon set for a SharePoint solution using a 24-pixel grid and `currentColor`.

## Improve

1. Improve these SVG icons so they use a consistent viewBox, stroke width, rounded line joins, and theme-aware colour.
2. Update this informative status icon so a screen reader announces “Overdue” once, without duplicating the nearby visible text.
3. Convert this clickable SVG into an accessible native button without changing its visual appearance.

## Audit

1. Audit the icons in this HTML dashboard for accessibility, visual consistency, dark-mode readiness, and remote dependencies. Correct the markup.
2. Identify which SVG icons in this page should be decorative, informative, or interactive, and explain the required markup changes.
3. Check whether these success, warning, and error icons communicate meaning without colour.

## Expected checks

A successful result should:

- classify icon purpose;
- use a valid viewBox;
- hide decorative SVG;
- label meaningful graphics without duplication;
- use native controls for interactions;
- preserve keyboard focus;
- avoid colour-only meaning;
- support responsive sizing and themes;
- avoid scripts and remote dependencies;
- include a concise validation summary.
