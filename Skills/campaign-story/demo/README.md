# Campaign Story — Demo Content

Finished sample output for the [campaign-story](../) skill. This file is for humans browsing GitHub. Do not upload the `demo/` folder to SharePoint Skills.

## What's included

`sample-files/NexusFlow-Velora-Freight-Campaign-Story.html` is a labelled fictional one-minute customer story:

- Product: NexusFlow
- Customer: Velora Freight (fictional)
- Arc: pain → three improvement moments → 41% fewer delayed deliveries (fictional) → payoff
- Playback, narration, voice picker, action cards, and confetti finale

## Setup

1. Open the HTML in a browser, or upload only that file to a document library if you want to show the finished artifact on a site.
2. Install the inner package `campaign-story/campaign-story/` into **Agent Assets → Skills**.
3. Ask Copilot: *"make a premium B2B story demo"* or *"create a campaign story from this brief"*.

## What to expect

The skill writes a new self-contained HTML story into the site **Reports** library. It should match this sample's structure and motion, with new scene data from the source you give it. Velora Freight and the 41% figure stay in the sample only.
