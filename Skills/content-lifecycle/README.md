# Content Lifecycle Management

Manages the content lifecycle for SharePoint documents — set retention labels, archive old content, manage expiry dates, and enforce deletion policies.

![preview](./assets/preview.png)

## What you get

- **Retention labels** — Apply, view, or remove retention labels on documents and libraries
- **Archive management** — Identify content older than a threshold and recommend actions
- **Version history cleanup** — Guide users to reduce excessive version counts
- **Expiry review** — Find content past its expected retention period and flag it
- **Safe by design** — Preview before acting, double-confirm before deletion, never auto-delete versions

## When to use

Ask Copilot:

- *"Find documents that haven't been modified in over a year"*
- *"Apply the 7-Year Retention label to this contract"*
- *"What retention label is on this document?"*
- *"Help me archive old content"*
- *"Clean up version history on large files"*
- *"Show me expired content in this library"*
- *"Manage document lifecycle for this site"*
