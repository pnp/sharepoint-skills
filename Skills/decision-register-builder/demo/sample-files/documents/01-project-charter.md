# Project Aurora — Project Charter
Project Manager: Anna Keller
Sponsor: Daniel Weber
Target Go-Live: 30 October 2026

The project replaces the customer case-management solution with a Microsoft 365 workspace.

The Steering Committee approves scope and go-live. The Architecture Board approves production hosting and architecture choices.

The project will evaluate the existing managed hosting service and Azure-based hosting for document conversion. A final production hosting decision is required before deployment planning can be completed.
