# Guided Form demo

This folder is for local checks only. Do not upload it with the skill package.

## Event Feedback

Open `../guided-list-form/reference.html` in a browser to see the Event Feedback sample at the welcome step. The sample uses a fictional Event Feedback list with Title, Full name, Email, Role, Rating, Would recommend, and Comments.

The local file never writes to a SharePoint list. Submit only fills a hidden form and shows the finish screen; it does not talk to Copilot. Do not submit real tenant data from this demo.

## Other screens

Still images of the text, choice, rating, review, and finish screens, plus a second fictional topic (Community garden plots), are in `../assets/`.
