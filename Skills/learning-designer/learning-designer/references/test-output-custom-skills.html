3. Build

Build a personal skill

Each skill lives in its own folder and includes a SKILL.md instruction file.

Create

Required structure

My skill folder→SKILL.md
---
name: copyedit-this-presentation
description: Editorial review for an existing PowerPoint presentation.
---

Use when an existing presentation needs an editorial review.
Review slide text for clarity, consistent terminology, and overly dense bullets.

Expected output: for each suggestion, provide slide number, issue, and proposed wording.

Boundaries: do not invent facts, change figures, or alter approved claims. Preserve the author’s intent.

Editing approach: suggest changes only. Do not apply edits unless the user explicitly asks.

Practice exercise

Try it

Create the copyediting skill, run it on a practice presentation, and review its suggestions.

Success looks like

It identifies unclear text and inconsistent terminology without changing the intended meaning.

Add it to PowerPoint

  1. Open Manage skills.
  2. Select Add skill.
  3. Paste, upload, or add the skill from the designated OneDrive Skills folder.
  4. Enable it when you’re ready to use it.

Before you upload

  • Use a clear, action-oriented name.
  • Describe when the skill should be used.
  • Specify the expected output and boundaries.
  • Keep the package simple: PNGs, PDFs, and nested ZIP folders aren’t supported for skill ZIP uploads.
