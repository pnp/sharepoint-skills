# Narrated Story Animation — Demo Content

Sample output for the [narrated-story-animation](../) skill. Do not upload this folder to SharePoint Skills.

## What's included

- `sample-files/story-studio.html` — Story Studio reference with multiple story types (market entry and related arcs).
- `sample-files/Routewise-Fictional-Logistics-Customer-Story.html` — labelled fictional logistics customer story.

Open either file in a browser. Company names, people, quotes, and metrics in these files are fictional.

## Setup

1. Install only the inner package `narrated-story-animation/narrated-story-animation/` into **Agent Assets → Skills**.
2. Ask Copilot: *"make a story demo like the story studio"* or *"turn this case study into an animated story"*.
3. The skill writes a new HTML file to the site **Reports** library.
