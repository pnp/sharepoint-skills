# Project Aurora — Project Charter

**Project:** Project Aurora  
**Project Manager:** Anna Keller  
**Sponsor:** Daniel Weber  
**Start date:** 6 April 2026  
**Target go-live:** 30 October 2026  
**Business area:** Customer Operations

## Objective

Project Aurora will replace the existing customer case-management solution with a modern Microsoft 365 based workspace. The project will migrate active case data, introduce standardized document handling, and provide a simplified user experience for approximately 350 users.

## Success criteria

- Production go-live no later than 30 October 2026.
- All critical and high-priority security findings resolved or formally accepted before go-live.
- Business acceptance completed before deployment approval.
- Support handover and operating documentation completed before production release.

## Governance

The project uses a weekly status report and the following controlled registers:

- Milestone Plan
- Risk Register
- Action Register
- Decision Register
- Deliverables Register

The Steering Committee meets every second Thursday. Material schedule changes, budget changes, and unresolved high risks must be escalated.

## Current delivery approach

The solution is delivered in four phases:

1. Discovery and design
2. Build and configuration
3. Integration and acceptance testing
4. Production rollout and handover
